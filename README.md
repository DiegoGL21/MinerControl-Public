# Miner Control

Miner Control es un videojuego de plataformas 2D en pixel art en el que un minero atrapado en una mina debe ascender, superar peligros y alcanzar la superficie.

> “No importa qué tan profundo caigas, siempre puedes volver a subir.”

## Características

- Plataformas 2D
- Ascenso vertical
- Salto con carga
- Plataformas móviles
- Lava ascendente
- Minerales coleccionables
- Sistema de vidas
- Guardado y continuación
- Final normal y final 100 %

## Tecnologías

- Godot 4.7.2
- GDScript
- Git
- GitHub
- GitHub Desktop
- Pixelorama
